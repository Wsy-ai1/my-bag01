# 04 · 需要哪些数据、去哪里拿、怎么拿

> 代码已经写好了，**卡住你的只会是数据和硬件**。下面是清单 + 获取步骤 + 每项的坑。

## 一、总清单

| # | 东西 | 你现在有吗 | 从哪来 | 用在哪 |
| --- | --- | --- | --- | --- |
| 1 | MVS SDK（含 `MvCameraControl.h`、`libMvCameraControl.so`） | ❌ 需下载安装 | 海康机器人官网下载中心（免费，需注册） | 编译 `hikrobot` 后端 |
| 2 | 海康 USB3 工业相机 + USB3 线 | ❌ 实验室借 | 实验室（讲义已说明由实验室提供） | 任务二取图、任务三标定、拍演示 |
| 3 | 圆点标定板（10×7，圆心间距 25 mm） | ❓ 向实验室确认 | 实验室借用；没有就淘宝买 | 任务三标定 |
| 4 | 能量单元 + 插它的货架/机构 | ❌ 实验室借 | 实验室 | 数据集拍摄 |
| 5 | X-AnyLabeling 4.3.1 Linux CPU 版 | ✅ 已有（447 MB 可执行文件） | 你 Downloads 里那个 | 标注 |
| 6 | 数据集图片（8~10 组 × 100~200 张） | ❌ 自己拍 | 手机或海康相机 | 数据集作业 |
| 7 | 可选：三脚架、补光灯、不同颜色背景布、转台 | ❌ | 自备/实验室 | 让数据更"多样" |

## 二、逐项获取步骤

### 1. MVS SDK

1. 打开 <https://www.hikrobotics.com/cn/machinevision/service/download>
2. 注册/登录海康机器人账号（要手机号验证）
3. 分类：**机器视觉 → 客户端 → MVS**；系统选 **Linux**、架构 **x86_64**
4. 下载 Ubuntu 对应版本（22.04 最稳），解压后 `sudo ./MVS.sh` 或 `sudo dpkg -i MVS-*.deb`
5. 验证：`ls /opt/MVS/include/MvCameraControl.h`、`ls /opt/MVS/lib/64/libMvCameraControl.so`
6. 跑 `bash scripts/setup_ubuntu.sh` 做权限/库路径/自检

坑：下载页面版本很多，选"Linux x86_64 + Ubuntu"；MVS 的图形客户端和 SDK 在同一个包里，不需要单独下 SDK。

### 2. 海康相机（实验室）

讲义原文要求：先群里说明 → 到实验室领取 → **只能在实验室内用** → 用完及时归还。

步骤：

1. 群里/负责同学处登记借用时间
2. 领相机 + **USB3.0 线**（普通 USB2 线供电/带宽不够，会出现枚举不到或掉线）
3. 在实验室机器上：`lsusb | grep 2bdf` 应能看到 `2bdf:0001` 之类
4. 插上后先开 `/opt/MVS/bin/MVS` 确认能出图、能改曝光
5. 拍完演示截图、采完标定图后，**先停采集再拔线**，相机与线放回原处

坑：相机被 MVS 客户端占用时，自己的程序打不开（`MV_E_HANDLE` / 访问失败）；测试前先关客户端。

### 3. 圆点标定板

优先向实验室借。借用前**必须做两件事**：

1. **数圆点**：横向几个、纵向几个（讲义示例是 10×7）
2. **量间距**：卡尺量相邻圆心距离，量 2~3 处取平均（示例 25 mm）

把结果写进 `configs/calibration.yaml`：

```yaml
pattern_cols: 10
pattern_rows: 7
center_distance_mm: 25.0
```

实验室没有、又需要自己买时，淘宝/京东搜：`圆点标定板 10x7 25mm 氧化铝` 或 `Halcon 圆点标定板 玻璃`，几十到两三百元。买回来仍然要重新量间距（标称值常有 ±0.01~0.05 mm 误差，够用但要按实际值填）。

坑：**行列数填反**（10×7 写成 7×10）会导致 `findCirclesGrid` 直接失败；间距填错会让 fx/fy 整体按比例偏大偏小。

替代方案（不推荐但可行）：有棋盘格就用棋盘格，但要改 `calib::detectGrid` 里的检测函数为 `cv::findChessboardCorners`，并把 `pattern_type` 改成棋盘格语义。

### 4. 能量单元 + 货架

实验室提供。拍之前先确认：

- 货架能插满能量单元（"满架 → 一个个取走 → 空架"这条要拍）
- 有没有不同颜色/材质的能量单元（不同外观都该出现）

### 5. X-AnyLabeling（你已有）

```bash
cd ~/Downloads
chmod +x X-AnyLabeling-v4.3.1-Linux-CPU
./X-AnyLabeling-v4.3.1-Linux-CPU
```

这是 PyInstaller 打包的单文件程序，不是 AppImage，**不需要 libfuse2**；但需要桌面库：

```bash
sudo apt install -y libgl1 libglib2.0-0 libxkbcommon-x11-0 libdbus-1-3 \
     libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 \
     libxcb-render-util0 libxcb-shape0 libxcb-xinerama0 libxcb-xfixes0 libxcb-cursor0
```

报 `libGL.so.1: cannot open shared object file` 就装 `libgl1`；报 xcb 相关就补上面对应的包。
远程服务器没桌面时，用 `ssh -X` 或干脆在本地 Ubuntu 桌面上标。

### 6. 数据集（自己拍）

这是工作量最大的一块，按 [03_数据采集与标注SOP.md](03_数据采集与标注SOP.md) 执行。要点：

- 8~10 组场景，每组 100~200 张
- 场景覆盖：机构上（满→空）、桌面/地面/不同背景、手持、远近、正/侧/端面、立/斜/躺、遮挡、部分出画、明暗/反光
- 1 个目标和 3~6 个目标同框都要有
- 两人配合，一个拍一个摆

### 7. 可选器材

| 器材 | 作用 |
| --- | --- |
| 三脚架/手机夹 | 固定机位，拍"距离变化"时更稳 |
| 补光灯 | 制造"亮一点/暗一点"的样本 |
| 纯色背景布（黑/白/木纹） | 满足"不同颜色背景"要求 |
| 转台 | 拍"不同角度"时不用手转，效率高 |

## 三、建议的时间线

| 时间 | 做什么 | 产出 |
| --- | --- | --- |
| 第 1 天 | 装 MVS + 跑 `setup_ubuntu.sh` + 用 `camera_opencv.yaml` 跑通代码 | 编译通过、笔记本摄像头能出图 |
| 第 2 天 | 借相机 + 标定板；`camera_test` 拍演示；`capture_calib` 采 18~25 张 | 演示截图 + `assets/calibration_imgs/` |
| 第 2 天晚 | `calibrate_camera` + `undistort_compare` | `camera_intrinsics.yaml` + 对比图 |
| 第 3 天 | 两人拍数据集（8~10 组） | `data/<缩写>_s01..s10/` |
| 第 4 天 | `prelabel.py` 粗标 + X-AnyLabeling 人工修 | 每组图片 + json |
| 第 5 天 | `dataset_qa.py` 清零问题 + `package_submission.sh` | 提交 zip |
| 第 6 天 | 写说明文档（取图流程/标定步骤/踩坑） | 提交说明 |

## 四、没有相机时的降级方案

| 目标 | 降级做法 |
| --- | --- |
| 跑通取图/显示/存图代码 | `configs/camera_opencv.yaml`（笔记本摄像头）或 `camera_video.yaml`（视频文件） |
| 演示帧率与界面 | 用 OpenCV 后端录屏，说明"上机后换 hikrobot 配置即可" |
| 标定 | 可以用手机拍标定板，但**内参只属于那台手机**；作业要求的是相机，尽量借到再标 |
| 数据集 | 手机专业模式完全够用（PDF 明确允许） |

## 五、文件放哪里

```
assets/calibration_imgs/     # 标定原图（15~25 张）+ 演示时 s 键存的图
configs/camera_intrinsics.yaml  # 标定输出
output/                      # 去畸变对比图、质检报告
data/<缩写>_s01/ ...          # 数据集（图片 + json）
datasets/energy_unit/        # 可选：转出的 YOLO 数据集
```
